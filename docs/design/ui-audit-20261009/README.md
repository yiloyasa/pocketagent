### 交互层补充观察（截图难以表达）
- **返回栈不稳定**：同样从二级页点返回，有时回列表、有时直接打开抽屉、有时跳到无关页（设置→返回曾直接落在"会话"）。
- **抽屉内容漂移**：同一会话内多次打开抽屉，"多 Agent 协同""新手教程"条目时有时无（疑似随连接/鉴权状态重算），导致坐标记忆失效、用户心智模型混乱。
- **未鉴权死路**：新建会话、"+"按钮点击无任何反馈（对比：其他页面会弹错误横幅）。
- **显示模式循环切换**：点击"跟随系统→浅色→深色"循环，但页面上其他同类行都是下拉展开，交互不统一（保存后有 Toast"显示模式已保存"，Toast 样式本身 OK）。

## 全 App 十大视觉问题 Top 10（跨屏共性，按严重度排序）

1. **导航容器混乱且主题割裂**：手机端套用平板式深色 icon rail + 可展开抽屉双形态，rail/抽屉永远深色而内容区浅色（深色模式下才统一）；抽屉条目还随连接状态动态增减，导航不可预期。
2. **错误态原始暴露且样式不一**：`UNAUTHENTICATED: token 无效` 等原始错误码出现在会话/文件/Git/设置控制台等 6+ 处；横幅有的带"重试"有的没有，颜色/位置/高度各异，且同一屏错误信息重复出现最多 4 次；没有任何一处给出"去配对"的引导动作。
3. **IA 与命名错位**：入口名 ≠ 页面标题成风——"文件"→"此电脑"、"连接与配对"→"用户数据管理"、"审批与沙箱"→"Agent 与模型"、"主机信任"→"用户数据管理"、"网页"→"内置浏览器"；设置存在重复入口（两个入口落同一页），二级页承载了多个设置分区的全部内容。
4. **卡片层级平、缺主次**：全 App 只有"白底+描边+大圆角"一种卡片，Home 三段、设置各节、说明卡、错误卡、纯文字卡全部同权重；唯一例外（协同页深色 hero 卡）反而显得突兀。
5. **留白节奏两极分化**：Onboarding 与外观页内容堆在上 1/3、下方大片空白；而排障页、用户数据管理、会话筛选区又是超高密度长文，页面内没有统一的间距/分组节奏。
6. **控件与色彩系统不统一**：主 CTA 有蓝底、黑底、浅蓝底三种；chips 选中是黑底白字、tab 选中是黑 pill、列表选中只有小字；"跟随桌面"类下拉、循环切换下拉、自定义"值|箭头"行三种交互并存。
7. **空态质量参差、无体系**：至少 5 种风格——图标+文案+CTA（会话/任务中心）、磁盘动画图（文件）、纯错误横幅无空态（Git）、"怎么用"文字卡（网页）、零值统计卡（任务中心）；空态图标还互相复用（checklist 图标既代表会话又代表任务）。
8. **未连接/未鉴权态缺乏整体策略**：几乎所有主机侧功能（模型、审批、控制台、Git、终端）在 token 无效时仍展示完整可交互外观，实际全部不可用；没有统一的"未就绪"降级样式，导致满屏不可点的假按钮。
9. **长文案无结构化设计**：排障 ①-⑤ 大段文字、审批弹窗教程式正文、空态里的"左右滑动可切换"导航教学等，都以整段文字塞进卡片，缺列表化/折叠/链接化处理。
10. **吸顶与遮挡细节缺陷**：Home/设置顶部连接卡吸顶，滚动时与内容重叠遮挡（截图 09/15/16 可见内容从卡底露出）；伴随返回栈行为不稳定、未鉴权按钮无反馈等交互硬伤，整体"完成度感"受损。
