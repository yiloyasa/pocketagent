# PocketAgent UI 审美调研：国内主流 App 设计语言

> 调研时间：2026-10-14 · 范围：微信、支付宝、小红书、抖音、B站、飞书、钉钉、夸克、WPS、腾讯文档/石墨文档、豆包/Kimi/通义
> 用途：Flutter 重构 UI 设计依据（与竞品调研、Flutter 可行性报告并列为三份输入）

## 一、逐个 App 设计语言

### 1. 微信（WeUI）
- 主色 Standard Green `#07C160`；黑白灰为主，绿色小面积点缀；扫一扫蓝 `#10AEFF`
- 暗色：深灰底非纯黑（`#1F1F1F` 家族）；企业微信深色色值表——蓝按钮 `#267EF0`→`#338CFF`、红 `#FF3C32`→`#FF4C42`、分割线 `#000000 7%`→`#4D4D4D 35%`、次要文字 `#CCCCCC`→`#747678 50%`、白气泡 `#FFFFFF`→`#222324`
- 圆角克制（4–8pt 量级）；卡片化程度低，白底+分隔线列表，密度高
- 底部 Tab 2–5 个；确认交互为全屏中间确认页（收款方+金额→底部主按钮→验密→成功页）
- 字号 22/17/15/14/12 pt

### 2. 支付宝（Ant Design Mobile）
- 品牌蓝 `#1677FF`，蓝色板 `#E6F4FF/#BAE0FF/#91CAFF/#69B1FF/#4096FF/#1677FF/#0958D9/#003EB3/#002C8C/#001D66`；功能色红 `#F5222D`、绿 `#52C41A`
- 暗色：背景三层 `#1F1F1F / #141414 / #000000`；文字不透明度 85/65/45%（禁用 30%）；分割线实色 `#434343`/`#303030`；阴影加深 4 倍位移不变；避免大面积纯白
- 圆角 XS=2/SM=4/LG=8（Card/Modal）
- 支付确认全屏页+底部主按钮

### 3. 小红书
- 品牌红 `#FF2442` 唯一饱和强调色；莫兰迪色系+中性灰
- 暗色浮层灰阶策略；大圆角卡片，近乎零阴影；宽松留白
- 双列瀑布流圆角卡片

### 4. 抖音（Semi/Arco Design）
- 品牌红 `#FE2C55`；Semi 示例 primary `rgb(142,84,233)`、secondary `#21C6C3`
- Arco「科学暗黑模式」：编译时基于主色算亮/暗两套梯度色板 + CSS 变量运行时引用
- 圆角约 6px 统一；娱乐化大卡片

### 5. B站
- 品牌粉 `#FB7299` + 辅色青蓝 `#00A1D6`（按钮/链接）
- 2023 后官方深色模式；中等偏大圆角；标题 15–17px、正文 14px、辅助 12px

### 6. 飞书（重点参考：审批交互）
- 品牌蓝 `#1456F0`；V5.0 深色模式+三主题换肤
- 「更多大圆角和卡片化」；**同一界面不超过 2 种圆角**；卡片色与背景色必须拉开层级，投影不省略
- **审批单据页：操作按钮收敛在页面底部**——「通过」「拒绝」主按钮突出，其余操作（退回、转发）收敛进「更多」；支持二次确认弹窗（标题+正文可配）
- 字号层级 12/14/16/20/24

### 7. 钉钉（Ding Design）
- 标准色 `#3296FA`（PANTONE 2184C），辅色 `#0DA4FF`、深蓝 `#235FF5`、navy `#022382`、浅蓝 `#B9E1FF`、灰 `#777777`
- 圆角分级统一定义；酷卡片支持黑白双模式

### 8. 夸克
- 科技蓝（约 `#2E6BFF` 量级）；蓝白极简；大圆角卡片+胶囊按钮；AI 对话式大留白

### 9. WPS：品牌红（约 `#C70E0E`），红白灰，中等圆角
### 10. 腾讯文档：标准色 `#1E6FFF`（钴蓝），链接色为 4.5:1 对比度改用 `#175CEB`；独创「蓝灰色」中性色。石墨文档：石墨蓝 `#3370FF` 量级，「中国式简约素雅」
### 11. AI App（豆包/Kimi/通义）
- 豆包：蓝紫渐变；对话气泡+**Capability Card** 双轨；**快捷提问/智能追问/预填建议**三件套；气泡最大宽度不超过屏宽 80–90%（问的气泡极值约为答的 90%）
- Kimi：紫罗兰调；极简聊天，输入框固定底部，模型切换顶部，侧边栏历史与设置
- 通义：蓝白，顶部模型切换+底部输入栏
- 共性：流式输出=气泡+光标/渐变占位；工具调用=可折叠卡片（默认收起摘要行）；思考过程=浅色背景块+进度态

## 三、针对 PocketAgent 的可借鉴清单

### 1. 流式时间线（豆包/Kimi/通义）
- 用户气泡靠右（品牌色浅底），AI 输出靠左占满宽（表面色卡片）
- 气泡宽度 ≤ 屏宽 80–90%
- 流式：光标闪烁+渐显骨架；长输出顶部「生成中」进度条可停止
- 回答结束生成 2–3 个追问 Chip（横滑点击即发送）
- 时间戳灰色 12px 居左；头像用圆角矩形（Agent 图标）非圆形
- 状态语义：工具调用中=旋转图标+步骤名；完成=绿勾；失败=红警+可展开错误详情

### 2. 审批卡（微信支付确认/飞书审批）
- 底部弹层（Bottom Sheet）或全屏中间页，不嵌入聊天流
- 信息结构：顶部标题+风险等级徽标 → 关键信息区（命令/文件路径/影响范围，等宽字体）→ 上下文摘要（Agent 理由）→ 底部按钮区
- 主按钮（允许）靠右/满宽；次按钮（拒绝）描边弱化；其余操作收敛进「更多」
- 颜色语义：允许=品牌主色；拒绝/危险=红系；取消=中性描边。**审批主按钮不用红色**（国内心智红=拒绝）
- 破坏性操作（rm、force push）必须二次确认弹窗
- 超时：倒计时+超时自动取消（微信支付范式），避免挂起 agent

### 3. 工具调用卡（折叠/展开）
- 默认折叠：单行摘要（图标+工具名+关键参数+状态+耗时）——豆包 Capability Card 范式
- 展开：完整命令（等宽+语法高亮）、参数表、输出预览（截断 3–5 行+「展开全部」）
- 卡片圆角 12–16px，表面色比背景亮一阶（暗色 `#1F1F1F`→`#262626` 梯度）
- 命令卡右上角「复制」
- 连续工具调用合并为可折叠步骤组（「执行了 5 个步骤 ▸」）

### 4. 移动端 diff 方案
- 竖屏 Unified 单列；平板/横屏可切 Split 双栏
- 配色：删行 `rgba(248,81,73,0.15)` / 增行 `rgba(63,185,80,0.15)`（GitHub 暗色系）；行内高亮 0.4 透明度
- 仅显示变更行行号；长文件按 hunk 分段折叠
- 顶部文件名+「+N / -N」统计徽标（绿/红），hunk 间跳转
- 双指缩放字号、长按复制行、「查看文件」跳转完整文件卡

### 5. 配色与尺度建议
| 角色 | 值 |
|---|---|
| 页面背景 | `#0F1115` / `#12141A` |
| 卡片表面 | `#1A1D24` → `#23272F`（浮层） |
| 主色 | `#4F7CFF`（拂晓蓝系，介于飞书 `#1456F0` 与 Ant `#1677FF`） |
| 功能色 | `#22C55E` 成功 / `#F5484D` 危险 / `#F5A524` 警告 |
| Agent 标识 | `#8B5CF6`（紫，Kimi/豆包调性） |
| 文字 | `#E8EAED` / `#9BA0A6` / `#6B7078` / `#4B4F56`（85/65/45/30%） |
| 分割线 | `#2C3038` 实色 |
| 代码区背景 | `#0B0E13` |

- 圆角：按钮 8px、卡片 12–16px、底部弹层顶部 20–24px、头像 8–10px 圆角矩形；全界面 ≤ 2–3 种圆角
- 导航：底部 4 Tab（会话/工具/文件/设置）+ 抽屉放历史会话与连接配对
- 字体：标题 20/17 加粗、正文 15/14、辅助 12、代码 13 等宽

### 避坑
①暗色不用高饱和主色大面积铺底；②深色模式非简单反色，阴影换表面明度差；③审批主按钮不用红色；④气泡不超屏宽 90%。

**结论**：PocketAgent 走「飞书式大圆角卡片 + Ant Design 式暗色表面梯度 + 微信支付式全屏确认页 + 豆包式流式气泡与折叠能力卡」混合路线；配色深灰底 `#0F1115` + 拂晓蓝 `#4F7CFF` + 紫 `#8B5CF6` 点缀。
