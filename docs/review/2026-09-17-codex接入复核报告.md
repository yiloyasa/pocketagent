## 6. 使用方法与适用场景（面向最终用户）

**审批与反问**:手机上发起 Codex 任务后,凡是涉及"执行命令、改动文件、提升权限"的动作,会弹出对应类型的审批卡——命令卡显示完整命令与工作目录,文件卡列出将改动的路径,权限卡说明申请的读写/网络范围。点"允许"前请看清类型;Agent 中途若反问问题(如要你选方案),会以问答卡呈现选项,可直接点选或自由输入。注意:sudo 密码等**终端交互提示目前手机端还不能代为输入**,遇到命令长时间无响应大概率是卡在等输入(已知 ❌ 项)。

**额度与受管策略**:出发前先看一眼 设置→Codex→「额度」,确认主/次窗口余量、重置时间与积分,避免任务中途被限流。若你的电脑由企业/管理员托管,设置里的审批策略、沙箱、联网搜索会**只显示被允许的选项**,并标注来源原因——看不到某项不是 App 坏了,是策略不允许。MCP 集成页会显示每个服务的鉴权状态,据此判断某个工具为何不可用。

**会话组织**:会话列表顶部可按"全部/已归档/未分组/各分组"筛选;长按会话卡可移入分组、新建并移入、或分叉。分叉会复制出一条带「· 分支」标记的新会话(原会话不变),适合"从这里试另一条路"。聊天页"更多"里可回滚最近若干回合——它会裁剪对话历史但**不撤销已落地的文件改动**,请先确认再用 git 备份。常驻目标在会话详情里设定,会真正下发到 Codex 并随其状态机(进行中/完成/受阻)同步回手机。
