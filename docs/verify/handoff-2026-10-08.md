## 6. 坑库速查（踩过必录，新会话免重踩）

| 坑 | 规避 |
|---|---|
| Git Bash 里跑 `cmd`/`tasklist`/`netstat`/`schtasks` | 用户桌面闪 cmd 窗（红线）；用 bash 内建或 Go/Python 探针；杀 daemon 用 `paguard -kill` |
| 直接 `gradlew` 构建中文路径仓库 | Gradle 炸；必须 `_pa_gradle.py` / `build-ascii.ps1` 镜像包装器 |
| Gradle UP-TO-DATE 假绿 | 测试必须 `--rerun` + 核结果 XML 时间戳 |
| go 找不到 | `PATH="/c/Go/bin:$PATH"` 前缀 |
| vbs 写中文注释 | 编码炸；用 pythonw / hidewin 无窗链 |
| 产物没更新就报"没生效" | 「源码改对 ≠ 跑着的是新的」；apkanalyzer / 二进制 grep 自证 |
| USB 真机连不上 daemon | 先 `adb reverse tcp:7246 tcp:7246` |
| `set_model` 报 provider 错 | pi 1.0.2 handler 要求 provider/model 二元组显式在场 |
| 台账/共享单例测试水位 | 并发写共享单例的用例会互相污染，注意隔离（预收编轮教训） |
| proto 生成器版本注释行 | .pb.go diff 冒出"没动过的 proto"先看版本注释行再判断 |
| `ping ... > NUL` 在 Git Bash | NUL 会被当普通文件写入仓库（2026-10-08 已清理一个）；重定向用 `/dev/null` |
