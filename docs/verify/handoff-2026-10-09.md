## 6. 新增坑库条目

| 坑 | 规避 |
|---|---|
| Git Bash heredoc 里的 python `\\` 转义会被吃 | 补丁脚本用 Write 工具落盘再 `python file`，勿 heredoc 内联正则/转义 |
| 执行者并行编辑同一文件互踩 | 派发时按文件所有权严格分区；半成品断点用"括号深度剖面+difflib 对齐 HEAD"定位 |
| `asFrameworkPaint` 在本项目 Compose 版本解析失败 | 直接用 `android.graphics.Paint()`（Compose Paint() 在 Android 本就包它） |
| compose `Stroke` 在 `graphics.drawscope` 非 `graphics` | import 路径照 PaGlass.kt 先例 |
| 测试期望与实现拼接守恒冲突 | 先算实现语义（缩进并入/末行合并），改测试并注释守恒依据 |
| 限额中断的半成品执行者 | git status 逐文件 diff 审计；能救则救（本波 D 路半成品修复后全绿入库），不能救则 checkout 单文件重放 |
